Public development history

What’s new in ArchivKauz?

A public look at the development process, without presenting private test packages or unreleased features as a finished product.

Current application version0.1.0-alpha.1-dev.10
Internal alpha – no public software download

Status: 28 November 2026

Development so far

Alpha milestones

dev.10Latest

Website builder

One published website can serve as the installation homepage. Multiple websites appear in a portal directory. Four themes, custom content pages and navigation; controlled publication and withdrawal. No public publication of collection objects or media yet.

dev.9

System configuration & Scaleway S3

Local or private S3 object storage, connection validation and controlled transfer of existing media. A live Scaleway account still needs to be tested.

dev.8

Media library

Upload multiple files, preserve originals, generate previews, detect duplicates using checksums and associate media with objects; protected downloads.

dev.4–7

Licensed test installation

Web installer with a valid test licence, regular licence checks, automatic domain/version reporting for security communications, and read-only mode with authorised export.

dev.1–3

Core foundations & collections

Initial installer, multi-factor login, permission foundations, object drafts, collections, inventory numbers, search and history.

These entries are a public summary of internal alpha milestones, not public software releases. Dates and final feature scope are not committed.

Outlook

What comes next?

  1. Public object and media publication with search
